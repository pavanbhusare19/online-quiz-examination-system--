

\# 🎓 QuizMaster – Online Quiz \& Examination System



QuizMaster is a responsive full-stack web application that allows users to take online quizzes, answer multiple-choice questions, and view their examination results.



\## ✨ Features



\- 📊 Interactive dashboard with quiz statistics

\- 📝 Multiple-choice quizzes

\- ⏱️ Countdown timer for examinations

\- 📈 Automatic score calculation

\- 📚 Multiple quiz categories

\- 🗂️ Previous examination results

\- 💾 SQLite database integration

\- 📱 Responsive user interface



\## 🛠️ Technologies Used



\- HTML5

\- CSS3

\- JavaScript

\- Python

\- Flask

\- SQLite



\## 🚀 How to Run



1\. Clone or download this repository.

2\. Open the project folder in a terminal.

3\. Install dependencies:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



4\. Start the application:



&#x20;  ```bash

&#x20;  python app.py

&#x20;  ```



5\. Open your browser:



&#x20;  http://127.0.0.1:5000/

\## 🗄️ Database



SQLite stores quiz information, questions, correct answers, and examination results. The database is automatically initialized when the application starts.
